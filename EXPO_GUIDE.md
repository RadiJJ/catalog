## 🚀 Задание 2: Размещение сайта каталога на GitHub Pages

1. **Инициализация Git в папке проекта**:
   Выполните в терминале локально:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of clothing catalog"
   ```

2. **Создание репозитория на GitHub**:
   - Перейдите на [github.com](https://github.com) и нажмите кнопку **New repository** (`+` в правом верхнем углу).
   - Назовите репозиторий `clothing-catalog`.
   - Убедитесь, что выбран тип **Public** (Публичный).
   - Нажмите **Create repository**.

3. **Отправка кода на GitHub**:
   Выполните команды, указанные на странице GitHub:
   ```bash
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/clothing-catalog.git
   git push -u origin main
   ```
   *(Замените `YOUR_USERNAME` на ваше имя пользователя GitHub).*

4. **Активация GitHub Pages**:
   - Перейдите во вкладку **Settings** репозитория на GitHub.
   - Слева в меню выберите раздел **Pages**.
   - В блоке **Build and deployment -> Branch** выберите ветку `main` и папку `/ (root)`.
   - Нажмите **Save**.
   - Через 1-2 минуты обновите страницу. Вы увидите ссылку вида:
     `https://YOUR_USERNAME.github.io/clothing-catalog/`

## 📲 Задание 3: Подключение опубликованного сайта в WebView

1. Вернитесь в код `App.js` в Snack Expo.
2. В строке `10` замените URL на ссылку, полученную в Задании 2:
   ```javascript
   const GITHUB_PAGES_URL = 'https://YOUR_USERNAME.github.io/clothing-catalog/';
   ```
3. В окне эмулятора Snack Expo появится мобильный каталог одежды со всеми функциями:
   - Фильтрация по категориям (Женская, Мужская, Обувь, Сумки).
   - Просмотр карточек товаров и переход на `product.html?id=...`.
   - Выбор размера и добавление в Корзину.
   - Сохранение Избранного.
   - Быстрое оформление заказа с модальным окном и подсчетом итоговой суммы.

## 🛠 Особенности доработанного проекта `clothing-catalog`

1. **Динамический рендеринг**: База данных товаров (`PRODUCTS_DATA` в `js/main.js`) обслуживает фильтрацию, поиск и динамическую подгрузку страниц товаров.
2. **Поддержка LocalStorage**: Корзина и Избранное сохраняются локально в WebView контейнере.
3. **Мобильный интерфейс**: Тёплая минималистичная палитра (Warm Cream UI), адаптированная под мобильные экраны и вырезы безопасной зоны (`SafeAreaView`).
